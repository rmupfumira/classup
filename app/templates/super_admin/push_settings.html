Generate keypair

One-time setup. Creates a fresh P-256 keypair and stores it in system_settings.vapid_config. After this, any user can enable push from Settings → Notifications.

Push services (FCM, APNs, Mozilla) use this if they need to reach you about delivery issues. Stored as mailto:<email> in the VAPID JWT.

Send a test push

Fires a notification to every device belonging to the named user. Use this to verify the push pipeline end-to-end without enabling push on your own browser, or when a user reports "I'm not getting notifications" — you can confirm whether their devices receive it.

Danger zone — rotate keypair

Replaces the existing keypair with a brand new one. Every existing push subscription becomes unusable — affected users will see their device drop to "Off" in Settings → Notifications and must re-enable on each device. Only do this if the private key has been compromised.
